# Introduction

Project Forge is a local-first CLI tool that generates production-ready, full-stack TypeScript projects from composable modules. It is designed for **developers** and **teams** who want a consistent, auditable foundation without manual boilerplate.

## Core principles

- **Local-first.** Everything runs on your machine. No cloud account required.
- **Deterministic.** Same inputs always produce the same output.
- **Transactional.** Every mutation is backed up and rolled back on failure.
- **Composable.** Add modules one at a time. Transitive dependencies are resolved automatically.
- **Automation-ready.** JSON output and deterministic plans for CI and scripting.

## What you get

A complete monorepo with:

- React + Vite web application
- Hono + Cloudflare Workers API
- D1 database with Drizzle ORM
- Better Auth authentication
- Role-based access control
- User and admin dashboards
- Comment system
- Shared contracts, config, UI, and test utilities
