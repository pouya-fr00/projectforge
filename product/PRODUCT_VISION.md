# Product Vision

## Vision

Make repeated web-project foundations installable, inspectable, and trustworthy so developers spend their time on product logic instead of rebuilding the same infrastructure.

## Problem

Developers repeatedly recreate:

- workspaces and config;
- database layers;
- authentication and sessions;
- permissions;
- dashboards;
- admin navigation;
- comments and CRUD patterns;
- validation and error contracts;
- tests and CI.

This consumes time and effort, produces inconsistent quality, and reopens security mistakes.

## Solution

A focused project factory with:

- one well-supported starter;
- composable modules;
- a deterministic CLI;
- transactions and rollback;
- transparent generated code;
- machine-readable contracts;
- excellent documentation;
- first-class developer workflows.

## Differentiation

Project Factory is not valuable because each individual template is unprecedented. It is valuable because it makes reuse reliable:

```text
understand → plan → preview → install → verify → explain
```

## Product values

- clarity over magic;
- depth over breadth;
- safety over forced automation;
- local ownership over hosted lock-in;
- tested examples over marketing claims;
- documentation as interface;
- boring, stable foundations over clever generation.
