# Non-goals

Project Factory V1 will not:

- support every framework;
- generate product-specific business logic;
- replace understanding of the generated code;
- operate a production runtime for generated apps;
- hide provider costs of a generated app;
- guarantee safe automatic upgrades after arbitrary user edits;
- execute untrusted community installer scripts;
- promise one-command deployment;
- own user accounts or source code;
- claim that auth is production-safe without environment/configuration review;
- maintain a remote database of generated projects;
- collect usage analytics by default;
- include a paid edition or license gate in V1.
