# Product Definition of Done

V1 is done only when all are true.

## Core behavior

- Clean create succeeds on supported Windows and Linux environments.
- Every mutating command has accurate dry-run behavior.
- JSON output is schema-tested and stable.
- Dependency resolution is deterministic.
- Incompatible modules fail before writes.
- Reinstall is idempotent.
- Failure injection proves rollback.
- Path traversal and symlink escape tests pass.
- Project lock prevents concurrent mutation.
- `doctor` detects all specified corruption cases.

## Starter and modules

- Golden starter runs locally.
- All six modules install individually where valid.
- Required combinations pass the acceptance matrix.
- Generated routes/navigation/env/schema are deterministic.
- Auth/RBAC security review has no critical finding.
- Database migrations work from clean state.
- User customizations are not overwritten by sync.

## Documentation

- README answers what, why, who, prerequisites, quickstart, and next steps above the fold.
- Five-minute quickstart is tested from a clean environment.
- Every command and module has a dedicated reference.
- Every known public error code has a troubleshooting entry.
- Persian startup guide matches real commands.
- Two first-time-user documentation tests succeed without maintainer assistance.

## Public release

- MIT license and attribution audit complete.
- SECURITY, CONTRIBUTING, CODE_OF_CONDUCT, changelog, release notes ready.
- CI green from clean clone.
- Two real example apps generated by the released CLI.
- npm package contents are audited.
- No secret, private file, absolute local path, or unpublished idea is included.
- Release audit recommends publish.
- Owner explicitly approves push/publish/deploy/release.
