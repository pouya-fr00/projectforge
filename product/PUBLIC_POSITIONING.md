# Public Positioning

## Short description

A local-first, open-source project factory for building a tested React + Vite + Hono full-stack foundation with installable database, auth, RBAC, dashboard, admin, and comments modules.

## Honest promise

Project Factory helps you reach product-specific development faster. It does not build your business logic, replace security review, or support every stack.

## Recommended README headline

> Stop rebuilding the same full-stack foundations.

## Three proof points

1. Preview every change before installation.
2. Failed installs roll back instead of leaving a half-broken project.
3. Developers and CI automation use the same documented module contracts.

## Avoided claims

Do not claim:

- ten-times faster without measured evidence;
- production-ready for every environment;
- zero bugs;
- universal framework support;
- safe upgrade of arbitrary custom changes.
