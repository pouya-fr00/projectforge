# README Blueprint

1. Product name and one-line value.
2. CI/license/npm badges only after real publication.
3. Short “why” section.
4. Five-minute quickstart with expected output.
5. Before/after project flow.
6. Supported stack and modules.
7. “What Project Factory changes” transparency section.
8. Human use.
9. Automation and CI use.
10. Documentation links.
11. Examples.
12. Status and V1 limitations.
13. Contributing/security/license.

## Above-the-fold rule

A reader must understand the product and see the first runnable command without scrolling through architecture, badges, or a long feature list.

## Quickstart variants

- interactive;
- fully non-interactive;
- CI/automation.

Only show commands that CI tests.
