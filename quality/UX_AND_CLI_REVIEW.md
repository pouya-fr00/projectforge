# UX and CLI Review

Review from a first-time user perspective.

- Is the first command obvious?
- Are prerequisites checked before failure?
- Does dry-run clearly separate requested and transitive modules?
- Are file changes understandable?
- Are generated vs editable files explained?
- Does cancellation leave no changes?
- Do errors provide one safe next action?
- Does `--json` contain no mixed prose?
- Does non-interactive mode avoid prompts?
- Are Windows commands first-class?
- Is help output concise and complete?
- Does doctor explain pass/warn/fail?
- Can a user know what auth/database module does before install?
