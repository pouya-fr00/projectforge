# Release Readiness

Release candidate must have:

- complete product scope;
- green full test matrix;
- clean clone and packed npm tarball tests;
- generated examples from candidate CLI;
- current security review;
- current license/provenance audit;
- current docs usability evidence;
- all quickstarts tested;
- no critical/important known issue without explicit owner acceptance;
- reproducible build and package inventory;
- release notes and migration notes;
- no public action performed yet.
