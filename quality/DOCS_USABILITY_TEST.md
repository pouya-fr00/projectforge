# Documentation Usability Test

## Participants

At least two clean-slate readers with no hidden context.

## Tasks

1. Explain what the tool does.
2. Identify prerequisites.
3. Create a project.
4. Add auth and admin.
5. Find which files are safe to edit.
6. Recover from one scripted conflict.
7. Use the CLI JSON output.
8. Locate a known error code.

## Measures

- task completed;
- wrong turns;
- questions asked;
- command errors;
- pages visited;
- confusion quotes;
- time only as supporting signal, not a marketing claim.

## Release gate

No unresolved blocker or repeated major confusion.
